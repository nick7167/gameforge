# Emberhold Name Research (2026-09-03)

## Method
Checked each candidate against: US App Store (iTunes Search API, 7 countries), 
Google Play, Steam (storesearch API), web exact-phrase (Bing), YouTube, 
US trademarks (Trademarkia full-DB scrape incl. status + international class), 
domain availability (RDAP: .com/.app), GitHub handles.

## Findings

### EMBERHOLD (current working title) — RISKY
- Steam: "Emberhold" game EXISTS (2 apps: 3324490, 4142780) + EmberHold RSPS server + itch.io game
- USPTO: 1 record (99583787) DEAD/Abandoned, class 21 housewares — no live conflict
- App Store: no app named Emberhold
- Verdict: legally usable, but two Steam games share the name → discoverability + confusion risk

### EMBERFALL (single word) — NOT SAFE
- iOS: "Emberfall" EXISTS — a portrait roguelike survival game (same genre space!)
- Steam: "Emberfall", "Emberfall Idle", "Emberfall Demo", "Ember Fall" all exist
- USPTO: EMBERFALL class 9 (computer game software) filed 2019 = DEAD/Abandoned
- Live EMBER marks (none cover video games): Logitech (microphones), Ember Technologies (mugs), 
  Ember Sports (baseball motion capture), Ember Entertainment (SaaS), Ember Recreational Vehicles
- Verdict: AVOID single word

### TWO-WORD CANDIDATES — ALL CLEAN
Checked: Emberfall Realms / Emberfall Saga / Emberfall Rise / Emberfall Dawn
- US App Store (7 countries incl. US/GB/DE/FR/JP/CN/BR): CLEAN
- Google Play: CLEAN
- Steam: CLEAN
- Web exact-phrase (Bing): CLEAN
- YouTube exact-phrase: CLEAN
- USPTO exact-phrase (live + dead): NO matches
- Domains .com + .app: AVAILABLE (all four)
- GitHub handles: AVAILABLE

### Proximity context (existing ember games, no trademark conflicts with us)
- Ember Knights (Steam, no US TM), Ember Crusade IV (Steam, no US TM), Eternal Ember, 
  Last Ember: Idle Survivors, Ember Ruin (Play) — "Ember" prefix is common but 
  two-word Emberfall+X names are unclaimed

## Recommendation
1. **Emberfall Realms** — evocative, matches multi-chapter/biome structure, fully clean
2. Emberfall Saga — equally clean, slightly more generic
3. Emberfall Rise / Dawn — clean, weaker genre fit
- Before launch: file US trademark (class 9: downloadable game software; class 42: online services), 
  register domains + social handles
- Note: trademark search was via public aggregators (Trademarkia); formal USPTO TESS search 
  + attorney clearance recommended before filing
